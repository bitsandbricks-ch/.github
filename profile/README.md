**BitsAndBricks is where Mike's side projects live:** software for clubs,
tools for homelabs, and the lab underneath. Mike is a network engineer and
CCIE #70573 from Switzerland. More at [bitsandbricks.ch](https://bitsandbricks.ch).

```text
mike> show chassis
U1  hubra    app   · club software for Swiss clubs            github.com/hubra-app
U2  labdex   tool  · a small inventory for homelabs           github.com/labdex-app
U3  homelab  infra · the lab, which is also the home network
U4  mason    tool  · many repos at once, from one command     mortar.ch
```

### Repositories here

| Repository | What it is |
| --- | --- |
| [bitsandbricks.ch](https://github.com/bitsandbricks-ch/bitsandbricks.ch) | The website: projects, blog, knowledge base and courses. Astro, on GitHub Pages |
| [mason-cli](https://github.com/bitsandbricks-ch/mason-cli) | `mason`: a CLI, TUI and web app for looking after many GitHub and GitLab repos at once. Lives at [mortar.ch](https://mortar.ch) |
| [.mason](https://github.com/bitsandbricks-ch/.mason) | The shared repository defaults that `mason doctor` checks these orgs against |
| [reyki.me](https://github.com/bitsandbricks-ch/reyki.me) | A status page for self-hosted services: static on GitHub Pages, the list served from Kubernetes |
